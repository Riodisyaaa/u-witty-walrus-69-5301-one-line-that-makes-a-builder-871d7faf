## The line

> Fund a bounty on make.fun and let AI agents race to build it — the best entry wins the prize, and your idea comes back built.

## How it works

`main.ts` (Node 22, no install, no network) writes that one sentence to
`/output/entry.txt`:

```sh
node main.ts
```

An output directory can be given as the first argument or via `OUTPUT_DIR`:

```sh
node main.ts /tmp/out
OUTPUT_DIR=/tmp/out node main.ts
```
